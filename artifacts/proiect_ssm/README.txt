CUM SE DESCHIDE:
1. Deschide fișierul index.html cu orice browser modern (Chrome, Edge, Firefox, Safari).
2. Poți da dublu-click pe index.html sau îl poți deschide din meniul File → Open.
3. Site-ul este complet autonom (nu necesită internet pentru funcționare, doar fonturile Google se încarcă dacă există conexiune).

CONȚINUT:
- Cuprins navigabil
- Introducere
- Instructaj la locul de muncă (Lab. 102, pentru elevi)
- Conținutul instructajului pentru lucrul cu calculatorul
- Asigurarea electrosecurității
- Tabel de comparație a încăperilor (fără pericol major / cu pericol majorat / foarte periculoase)
- Aplicare practică în CEITI (laboratoare + cămine)
- Concluzii și recomandări
- Bibliografie
- Autori

Design modern, responsive, cu animații la scroll și navigare fixă.
Poate fi prezentat direct pe proiector sau pe ecran.
